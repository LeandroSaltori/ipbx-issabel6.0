# 🏷️ Identificação e Nomes dos Ramais (`src/nome_ramais/`)

Este diretório contém a interface e scripts para gerenciamento de apelidos e identificação visual de ramais no Issabel PBX.

---

## 📌 Opção do Menu Interativo: **[10] Nome dos Ramais**

Ao selecionar a opção **`[10]`** no menu **`ipbx-update`** (`ipbx-menu.sh`), este módulo é instalado em `/var/www/html/modules/nome_ramais/`.

### 🎯 O que este módulo faz:
1. Permite vincular nomes de setores, pessoas ou filiais a cada número de ramal.
2. Sincroniza os nomes para exibição em relatórios de bilhetagem (CDR), painéis de monitoramento e no discador webphone.
3. Facilita a consulta rápida de ramais sem necessidade de decorar os números.
